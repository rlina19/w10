Feedback: Enemies flinch
The goal of the game is to stop an alien dimension rift and survive. The character shoots an alien and the alien/enemy flinches.
Source Link: https://www.half-life.com/en/home/ 
Lecture: When creating a game know who your fans are. You dont want to listen to the feedback/opinions of everyone, only your fans who actually play your game or use your product. When getting negative feedback from fans take it into consideration to improve.

## R2 - Three engines and my choice
1. Godot. Supports both 2d and 3d. Uses C# and GDScript. One useful feature is that it uses nodes for easy building. https://docs.godotengine.org/en/stable/getting_started/step_by_step/nodes_and_scenes.html 
2. Unity. Supports both 2d and 3d. Uses C#. One useful feature is that you can deploy games on many platforms. https://docs.unity3d.com/6000.0/Documentation/Manual/UnityManual.html
3. Stride. Supports both 2d and 3d. Uses C#. One useful feature is that it has advanced graphics. https://www.stride3d.net/ 
I would choose to try Unity because its said to be beginner friendly and has good resources for developing games.
